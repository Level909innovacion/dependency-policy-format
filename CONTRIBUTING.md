# Contributing

The specification is at draft v0.0 and everything is open to change. The most useful contributions right now are:

- Pointing at an existing tool or format that already does what DPF proposes, in whole or in part.
- Telling us which construct in `spec/dpf-v0.0.md` your tool could not read or would read differently.
- Example policies from real projects (with identifiers changed if needed) so the conformance suite reflects practice.

Open an issue for any of these. Pull requests against the specification or the schema are welcome but please open an issue first so the change can be discussed.

## Generative AI

This project may use generative AI tools (large language models, code assistants) as an aid for drafting text, tests and documentation. All such output is reviewed, edited and approved by a human contributor who takes responsibility for it. Contributions that are purely machine-generated without human review are not accepted. Where a commit contains a substantial amount of generated content, the commit message says so and names the model used, following the [NLnet policy on generative AI](https://nlnet.nl/foundation/policies/generativeAI/).

## Conduct

Be factual and courteous. Disagreement about the design is expected and welcome.
